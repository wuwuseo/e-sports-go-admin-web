# 登录页重设计（极简浅色卡片）设计文档

- 日期：2026-09-12
- 状态：已与用户确认的设计（通过可视化预览逐轮选定）
- 范围：管理员登录页 UI 重设计；登录相关业务逻辑不变

## 1. 背景与目标

现有登录页（`src/views/login/index.vue`）采用"深色渐变背景 + 粒子动画 + 居中玻璃拟态卡片 + 特性胶囊"的装饰风格。用户希望重新设计登录界面 UI。

经可视化对比（左右分栏品牌型 / 极简浅色卡片 / 暗黑科技光效 / 现有方案精修四个方向），用户选定：

- **方向 B：极简浅色卡片** —— 浅灰底 + 白卡片 + 细边框，去装饰，靠留白与字重撑气质
- **变体 B2：极淡晕染背景** —— 在纯净浅灰底上叠加左上蓝、右下紫两团几乎不可见的品牌色光晕，与站内渐变主色（`--gradient-primary`）呼应

目标：视觉更克制、耐看，与 Arco Design 组件及站内 `design-system.less` 令牌体系一致；不改动任何登录业务逻辑。

## 2. 范围

### 做

1. 重写 `src/views/login/index.vue` 的模板与样式（页面壳层）。
2. `src/views/login/components/login-form.vue` 仅做必要的样式类微调（不改脚本逻辑）。
3. 删除死代码 `src/views/login/components/banner.vue`（Arco Pro 模板遗留，全库无引用，用户已批准）。
4. `.gitignore` 增加 `/.superpowers`（已完成）。

### 不做

- 不改 `login-form.vue` 的脚本逻辑：图形文字/图片点选/极验三种验证码、GitHub OAuth（条件显示）、记住密码、RSA 加密登录、中英文 i18n 全部保持现状。
- 不加"忘记密码"入口（后端无找回密码流程）。
- 不加页面级语言切换（语言跟随系统设置）。
- 不新增全局样式变量；不修改 `design-system.less`、全局 `Footer` 组件。
- 登录页壳层文案维持现有硬编码中文（"管理系统"、"欢迎回来"、"请登录您的账户以继续"），不做 i18n 改造（现状如此，另行处理超出本次范围）。

## 3. 布局结构（桌面端）

```text
┌────────────────────────────────────────────┐
│ ◆ 管理系统                    （左上角品牌）│
│                                            │
│              ┌──────────────┐              │
│              │  [渐变logo块] │              │
│              │   欢迎回来    │              │
│              │  请登录您的…  │              │
│              │  [用户名]     │              │
│              │  [密码]       │              │
│              │  ☑ 记住密码   │              │
│              │  [ 登 录 ]    │              │
│              │  — 其他方式 — │（条件显示）   │
│              │  [GitHub 登录]│（条件显示）   │
│              └──────────────┘              │
│                                            │
│        Copyright © 2026 Admin System       │
└────────────────────────────────────────────┘
背景：--bg-subtle 浅灰 + 左上蓝/右下紫极淡光晕
```

- 品牌：左上角固定，渐变小方块（`--gradient-primary`，18px，圆角 6px）+ "管理系统"（14px，700，`--color-text-1` 级深灰）。
- 卡片：宽 400px，白底，`1px solid var(--border-subtle)` 边框，`border-radius: var(--radius-xl)`（16px），柔和投影（一次性内联阴影即可，如 `0 12px 32px -16px rgba(15, 23, 42, 0.18)`），内边距 40px。
- 卡片头：居中渐变 logo 块（36px，圆角 10px，内置 `icon-settings` 白色图标）→ 标题"欢迎回来"（20px/700）→ 副标题"请登录您的账户以继续"（14px，次级灰）。
- 表单区直接渲染现有 `<LoginForm />`。
- 页脚：一行版权文字 `Copyright © 2026 Admin System`，居中、10-12px、最浅灰。**不再引入 `@/components/footer`**（其内容为 "Arco Pro"，与品牌不符；该组件文件本身保留不动）。

### 移除元素

粒子动画、玻璃拟态渐变背景、`--gradient-login` 使用、特性胶囊（加密传输/权限管控/操作审计）、品牌标语"高效 · 安全 · 智能"、`Footer` 组件引用。

## 4. 视觉规范

| 项 | 浅色 | 暗色（`body[arco-theme='dark']`） |
| --- | --- | --- |
| 页面背景 | `var(--bg-subtle)`（#f8fafc） | `var(--bg-subtle)`（#0f172a） |
| 光晕 | 蓝 `rgba(37,99,235,0.07)` 左上；紫 `rgba(124,58,237,0.06)` 右下 | 不透明度提高到 0.12 / 0.10 |
| 卡片背景 | `#fff`（`--bg-elevated`） | `var(--bg-elevated)`（#1e293b） |
| 卡片边框 | `var(--border-subtle)` | 同左（自动切换为 #334155） |
| 标题色 | `#0f172a` 级（`--color-text-1`） | `#f1f5f9` 级 |
| 输入框/GitHub 按钮 | Arco 组件默认 + design-system 全局增强 | 同左 |

- 全部颜色优先走令牌；光晕、卡片投影允许一次性内联 rgba 值（不新增全局变量）。
- 登录按钮：使用 Arco `type="primary"`，由 `design-system.less` 全局增强呈现 `--gradient-primary` 渐变，登录页不做特例覆盖。
- 动效：仅卡片入场一个轻量 `fadeIn`（0.3s ease），移除粒子浮动动画；不引入其他动画。

## 5. 响应式

- ≥576px：如第 3 节布局。
- <576px：品牌行改为卡片上方水平居中；卡片宽 `calc(100% - 48px)`、最大仍 400px；内边距收紧（约 24px 20px）；分隔线"其他登录方式"与 GitHub 按钮保持条件显示不变。

## 6. 验证码与 OAuth 的呈现（逻辑不变，仅皮肤适配）

- 图形文字验证码：输入框 + 右侧验证码图（现有 `captcha-row` 结构），仅随新皮肤调整间距/圆角。
- 图片点选验证码：提示条 + 点选图 + 状态行（现有结构），同样仅样式适配。
- 极验 4 代：信息提示条（`a-alert`），点击登录时弹出；验证码接口失败时错误提示条样式保持。
- GitHub 按钮：仅当 `showGithubLogin` 为真时显示（逻辑不变）。
- 表单错误提示条（`login-form-error-msg`）保留现有行为，按新皮肤调整配色。
